# Agent instructions

Follow `CONTRIBUTING.md` when preparing changes and pull requests.

## Agent skills

### Issue tracker

Use GitHub Issues through `gh`; before reading, publishing, or updating tickets, read `docs/agents/issue-tracker.md`.

### Triage labels

Use the five canonical triage labels; before triaging or changing triage labels, read `docs/agents/triage-labels.md`.

### Domain docs

Use a single-context glossary and ADR layout; before codebase exploration or domain work, read `docs/agents/domain.md`.

# DXS500 electrical testing

The DXS500 performs AC dielectric withstand tests and insulation-resistance
measurements on a specimen.

## Language

**AC Hipot test**:
A dielectric withstand test that applies a specified AC voltage to a specimen
and evaluates its current against the selected detection criteria.
_Avoid_: DC Hipot when referring to the standard DXS500 AC function

**Insulation-resistance measurement**:
A measurement of a specimen's insulation resistance under a specified DC test
voltage.
_Avoid_: Hipot when referring to resistance measurement

**Specimen**:
The item connected to the instrument for an electrical test or measurement.

**Parameter set**:
A numbered collection of stored settings for one measurement function.
_Avoid_: Default configuration when referring to a previously stored parameter set

**Test verdict**:
The pass or fail classification of a completed specimen test under its configured
criteria. A measurement value alone is not a test verdict.
